# Map

MapView is built on MapLibre GL with a Protomaps pmtiles basemap. The tiles
must be served (the demo app's local-tiles plugin, or a remote R2 URL);
playground is for component usage only — without tiles the map stays blank
but markers / tracks still render.

## Shanghai (markers + tracks + HUD)

```tsx preview
<MapView
  className="rounded-md h-96"
  basemap={{ url: "pmtiles:///pmtiles/shanghai.pmtiles", flavor: "light" }}
  center={[121.47, 31.23]}
  zoom={12}
  markers={shanghaiMarkers}
  tracks={shanghaiTracks}
  showCenterHud
/>
```

> One marker (咖啡A) intentionally keeps a Chinese label to demonstrate CJK
> label rendering (requires the glyph cache to contain CJK glyphs).

## Custom Attribution

Pass `attribution` at init to override the default `PROTOMAPS_ATTRIBUTION`
(shown in the bottom-right attribution control).

```tsx preview
<MapView
  className="rounded-md h-96"
  basemap={{ url: "pmtiles:///pmtiles/shanghai.pmtiles", attribution: "© Example data source" }}
  center={[121.47, 31.23]}
  zoom={12}
  markers={shanghaiMarkers}
/>
```

## API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `basemap` | `{ url, flavor?, lang?, glyphs?, attribution? }` | — | pmtiles URL + Protomaps flavor (light / dark / white / black / grayscale) |
| `center` | `[number, number]` | — | Map center |
| `zoom` | `number` | — | Zoom level |
| `maxBounds` | `[[lng,lat],[lng,lat]]` | — | Camera constraint |
| `markers` | `MarkerSpec[]` | `[]` | Markers (label / emoji / popupContent / color) |
| `tracks` | `TrackSpec[]` | `[]` | Tracks (name / color / coordinates / closed) |
| `openMarkerIndex` | `number` | — | Marker popup auto-opened on first render (default: none) |
| `showCenterHud` | `boolean` | `false` | Live center / zoom HUD |
| `navControl` | `boolean` | `true` | Navigation control |
| `className` | `string` | — | Container class (controls size) |
| `onMapReady` | `(map) => void` | — | Style-loaded callback |
| `onClick` | `(e) => void` | — | Click event |
| `onMove` | `(e) => void` | — | Move event |
| `onZoom` | `(e) => void` | — | Zoom event |
| `onIdle` | `(e) => void` | — | Idle event |
