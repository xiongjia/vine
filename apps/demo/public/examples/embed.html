Embeddable map widget

createMapWidget — plain HTML, no React

The map above is a self-contained widget (packages/ui/dist/widget/map-widget.js) mounted with createMapWidget(el, options). The host page only serves the pmtiles basemap (HTTP Range) and glyphs — everything else is bundled.

☕ Switch markers — calls w.setData({ markers }) to replace the markers with the English Tokyo landmarks; press again to toggle back to the Shanghai ones.

📍 Fly to Bund — calls w.flyTo({ center, zoom }) to move the camera to the Shanghai Bund (a recognizable landmark).

Basemap dropdown — calls w.setBasemap(url, { center, zoom }) to switch between the Shanghai and Tokyo region files at runtime; the map is recreated with the new pmtiles file.
